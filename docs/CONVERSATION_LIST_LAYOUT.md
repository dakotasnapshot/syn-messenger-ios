# Conversation-list sidebar surface

The split view supplies `isInSidebar` to its primary column. `HomeScreenContent` uses that context to give the conversation-list viewport a 24-point continuous rounded outline aligned to the scroll view’s measured top content inset and a 32-point alpha fade at its bottom edge. The list extends through the bottom container safe area without ignoring the keyboard safe area. A 40-point scroll-content bottom margin lets the final conversation move fully above the fade before selection. The fade is a mask, not an overlay that intercepts taps. The canvas background belongs inside that mask; a separate opaque HomeScreen background would fill the rounded corners and restore the hard lower edge. The mask follows `onScrollGeometryChange` content insets because an ancestor GeometryReader can report zero top safe-area inset even when the native navigation bar covers the scroll view.

Sidebar conversation rows use continuous 14-point corners with small horizontal and vertical insets, including the selected background. Existing retro-theme corner/inset choices remain. Compact navigation retains its original list surface, navigation clearance and row geometry; no device-idiom checks or hardcoded screen dimensions are used.

## Adaptive avatar rail

The Chats primary column accepts widths from 96 to 420 points; Spaces retains its existing 280–380-point bounds and has no avatar-rail resize handle. Chats uses stable sidebar/detail coordinator modules in an explicit horizontal pane because iPadOS clamps the native split view to a 280-point minimum, even with smaller declared or preferred widths. Its trailing resize handle drives the actual sidebar frame; the detail pane retains a Show/Hide Sidebar control. Compact navigation and Spaces keep their original native navigation paths. The handle also provides an adjustable accessibility action. Its live measured width supplies `sidebarExpansion`, clamped from zero at 140 points to one at 280 points. Conversation previews fade as the column narrows; at the narrowest sizes, room avatars remain centered, selected and tappable, with unread dots and accessible room names. Invitations and pending knocks retain their existing selection actions, including the invitation avatar-privacy preference. The custom pane already positions its viewport beneath the navigation toolbar, so its surface mask uses zero additional top inset; applying the native split-view inset again would hide the search field or first avatar. Sidebar search is an in-content field sharing the existing query/search-mode bindings; nonempty submitted queries keep filtering after keyboard dismissal, while collapsing to the rail cancels and clears search. compact navigation retains native search. This keeps native search-bar insets from masking the first avatar when the header collapses. A compact Sidebar actions menu replaces the title/actions below the expansion threshold and retains Settings, Start chat, space filters and Chats/Spaces navigation. Expanded controls return when widened. Reduced Motion disables the width-transition animation. Navigation and draft ownership do not change when the sidebar width changes.

Message focus uses an indigo/purple background instead of Compound's green accent gradient. Text message accessibility exposes the actual rendered text view rather than an offscreen representation clone, retaining sender context and the Message actions accessibility action. Read-only message text uses native selection handles; the message long-press recognizer yields touches inside the text view to UIKit. Long-press bubble margins for the existing message actions, or use the existing context menu and swipe-to-reply. Selection does not make messages editable. Links keep their existing open/confirmation handling.

`testSidebarCompressesAndExpandsWithoutLosingDraft` drags the sidebar resize handle and checks the menu, selected-room target, restored previews and retained draft. `testPartialMessageTextCanBeCopiedIntoComposer` copies a native text selection and requires the pasted value to be a proper substring, not the entire message. Use native MenuItem roles for Copy/Paste and double-tap a measured first-line word position rather than the text-view center, which can be whitespace when the message wraps. Native runtime outcomes are recorded separately from these test definitions.

## Pane surface continuity

The resizable Chats pane clips its inner navigation surface to an 18-point continuous curve inside a 6-point inset, matching the outer 24-point curve. Both the pane frame and the horizontal split backing use Compound's theme-aware canvas rather than mixing material and opaque black surfaces. The sidebar navigation toolbar explicitly uses the same canvas; non-sidebar navigation retains its standard bar style and automatic visibility. These changes apply to both expanded conversations and the narrow avatar rail without replacing navigation modules or draft ownership.
