# Reporting a Vulnerability

Report SYN Messenger vulnerabilities privately to [founder@synmessenger.com](mailto:founder@synmessenger.com).

Include affected version, platform, reproduction steps, and impact. Do not include passwords, access tokens, recovery keys, or private message content. Reports concerning unmodified upstream Element X code may also be reported through [Element's security policy](https://element.io/security/security-disclosure-policy).
