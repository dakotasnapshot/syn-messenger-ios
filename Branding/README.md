# SYN Messenger branding

Official SYN Messenger artwork is available in this directory and in the website assets.

## Source artwork

- `SYN-AppIcon.svg` — scalable app icon source.
- `SYN-AppIcon-generated.png` — 1024×1024 raster master.

## Website and directory artwork

- `Website/public/logo.svg` — scalable SYN logo suitable for client directories.
- `Website/public/syn-icons/1024.png` — full-size square icon.
- `Website/public/syn-icons/512.png` — medium square icon.
- `Website/public/syn-icons/180.png` — Apple touch icon.
- `Website/public/syn-icons/152.png` — iPad touch icon.
- `Website/public/syn-icons/144.png` — high-density web icon.
- `Website/public/syn-icons/120.png` — iPhone touch icon.
- `Website/public/syn-icons/24.png` — compact web icon.

SYN Messenger branding may be used to identify or link to the official applications. The application source remains licensed under the terms in the repository root.
